OB on-device browser agent · evaluation bench

Three synthetic targets, five scored metrics, zero real PII

Open a demo page, run the agent from the extension sidepanel, and watch the twin lightbox show what stays on your device versus what the reasoning server receives. The evaluator replays the same perception code offline for reproducible scores.

Run the evaluation

# 1. reasoning server (any terminal)
cd server && pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000

# 2. demo pages (this directory)
python3 serve.py            # http://127.0.0.1:8080

# 3. extension: chrome://extensions → Load unpacked → extension/

# 4. automated scoring (offline, deterministic)
python3 evaluator.py

Competition metrics

MetricWeightMeasured as
Accuracy of visual context25%F1 of perceived interactive elements vs ground truth (selector-level; hidden decoys must be dropped)
PII detection recall & precision20%TP/FP/FN over sensitive fields + face regions; vision boxes matched at IoU ≥ 0.3
Precision of redaction20%Mean IoU of applied boxes, full coverage of sensitive regions, over-mask penalty — hard-gated on irreversibility verification
Client resource utilization20%JS heap (MB) + perception latency (ms) while executing the real extension modules in Node
End-to-end latency15%Perception + redaction + server round-trip per cycle; live numbers also shown in the sidepanel telemetry bar

What never leaves the device

Raw screenshots, element values behind tokens, vault contents, and the raw pane of the inspector are extension-process-local. The outbound payload is re-scanned by a leak assertion before every request — if any raw value or PII-shaped string survives, transmission is blocked and the step aborts.

Synthetic evaluation environment — every datum on these pages is fabricated.
